# Qarğa SEO Workspace

Use `.qarga-seo/` as the durable strategy workspace. Keep technical audit findings, keyword/category hypotheses, location-page rules, structured-data requirements, content briefs, roadmap, and changelog separate from production code.

Do not mass-generate thin pages. Every proposed programmatic page class must have genuine user value, unique data, crawl/index rules, canonical strategy, internal linking, and quality gates. Search volume/ranking claims require a named data source; otherwise label them hypotheses.

Publishing, external SEO-tool writes, Search Console changes, or large-scale page generation require project-owner approval.
