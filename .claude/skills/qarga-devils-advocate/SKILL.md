# Qarğa Devil's Advocate

Use for material decisions where a plausible downside could change the project owner's choice. Do not create friction for routine execution.

Challenge the proposal across relevant dimensions: user value, provider incentives, unit economics, legal exposure, refund/chargeback burden, fraud, support load, privacy/security, technical complexity, scalability, reversibility, measurement, and opportunity cost.

For each meaningful objection mark it RESOLVED, ACCEPTED RISK, NEEDS EVIDENCE, or BLOCKING. Present a better alternative when one exists. Never invent data to strengthen an argument. Final money, legal, risk-acceptance, and irreversible scope decisions remain with the project owner.
