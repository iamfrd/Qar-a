---
description: Turn an owner request into a persistent Work OS parent task, then decompose it into agent-owned subtasks with dependencies, reviewers, acceptance criteria, and KPI points.
---

Use `qarga-work-os`, `qarga-completion-contract`, `qarga-workflow-routing`, and `qarga-planning`.

Create the parent task first. Research the current repository before creating implementation subtasks. Assign one primary agent and one independent reviewer per subtask. Add explicit dependencies rather than relying on conversation order. Base points must be assigned before execution. If a material owner decision is missing, open a decision gate instead of pretending the task is ready.
