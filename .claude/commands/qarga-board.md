---
description: Open or summarize the persistent Qarğa Work OS board and surface active work, owner decisions, blockers, and ready agent queues.
---

Use `qarga-work-os`.

1. Run `npm run work-os:validate` and `npm run work-os:summary`.
2. Summarize active work, blockers, owner decisions, review queue, and Done progress in Azerbaijani.
3. If the user asks for the visual board, run `npm run work-os:serve` only when an interactive local process is appropriate; otherwise explain the command and localhost URL.
4. Do not manually mark unfinished work DONE.
