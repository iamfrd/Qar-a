# Strategic Readiness Roadmap

## 1. Technical completion

- inventory every screen as real, partial, or mock-only;
- complete typed API integration;
- stabilize deterministic tests;
- add critical journey smoke coverage;
- close security and reliability gaps.

## 2. Revenue and payment readiness

- choose the provider value event;
- compare commission, fixed fee, subscription, sponsored placement, and hybrid options;
- create event and audit data;
- run a manual pilot before complex payment engineering;
- define refund, dispute, settlement, and support ownership;
- obtain legal and owner approval before live payment.

## 3. Support readiness

- define ticket taxonomy, severity, escalation, ownership, knowledge base, personal-data handling, provider/student status visibility, and product feedback loops.

## 4. Go-to-market readiness

- define personas, positioning, supply/demand launch order, measurement, channel hypotheses, support readiness, and “do not launch yet” gates.

Marketing execution begins only after product, measurement, supply, support, revenue, privacy, and operational ownership are ready.
