# Sandboxed Autonomous Workers

Future 7/24 coding automation should run in disposable isolated environments rather than on production or a privileged workstation. See `.claude/automation/sandbox-policy.json` and the `qarga-sandbox-autonomy` skill.

The safe output boundary is a Draft PR plus evidence. Merging, deployment, money movement, legal decisions, auth/permission changes, destructive database operations, and external-account writes remain human-gated.
