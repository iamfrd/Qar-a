# claude-code-templates Adaptation for Qarğa

The uploaded reference repository was treated as a pattern library, not as a replacement runtime. Qarğa keeps its coordinator, specialist roster, project memory, performance governance, and owner gates.

Adapted concepts include completion contracts, anti-spin loops, builder/reviewer separation, devil's-advocate review, human approval loops, subagent lifecycle telemetry, staged secret protection, system health, Playwright-ready E2E structure, k6 load template, production-error workflow, analytics/pricing/SEO/support patterns, ticket-to-Draft-PR architecture, and read-only 7/24 health/KPI worker templates.

Not copied wholesale: hundreds of generic agents/skills, competing coordinator templates, framework-specific templates, unpinned external security downloads, automatic production writes, generic memory systems that conflict with Qarğa project memory, and hooks that mask failed tests.
