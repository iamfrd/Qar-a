# Project Memory Templates

Use these templates to create input files for the append-only Qarğa project-memory registries.

Commands:

```bash
npm run decision:record -- docs/project-memory/DECISION-TEMPLATE.json
npm run debt:record -- docs/project-memory/TECHNICAL-DEBT-TEMPLATE.json
npm run experiment:record -- docs/project-memory/EXPERIMENT-TEMPLATE.json
npm run project-memory:review
```

Copy a template to a task-specific filename before editing it. Do not use the template IDs in real records. Never include credentials, secrets, personal data, or invented metrics.
