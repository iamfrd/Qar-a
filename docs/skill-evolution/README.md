# Qarğa Skill Evolution

Qarğa does not promote skills because they sound better. Repeated evidence triggers read-only capability research. Approved candidates are authored separately, independently benchmarked against a baseline on disjoint validation and hidden-holdout cases, reviewed for regressions, then piloted on at least three relevant real tasks before permanent promotion.

Roles are separated: `qarga-skill-researcher` diagnoses capability gaps, `qarga-system-improver` authors approved candidates, `qarga-evaluation-engineer` designs and scores benchmarks, and `qarga-system-reviewer` reviews persistent system changes. The project owner controls permanent promotion where policy requires approval.

Rejected candidates and failed hypotheses are preserved so the system does not repeatedly rediscover the same bad idea.
