# Qarğa Controlled System Evolution

Qarğa can discover and propose improvements continuously, but permanent system behavior is not self-modified silently.

Evidence → `qarga-system-researcher` → smallest-change proposal → project-owner approval when required → `qarga-system-improver` → `qarga-system-reviewer` → policy-defined pilot → KEEP / REVISE / REVERT.

Separation of duties is mandatory. Researcher is read-only. Improver implements approved scope only. Reviewer is independent. High-impact persistent changes are owner-controlled and reversible.

Use `npm run evolution:review` to see open research, approvals, reviews, pilots, and promotion candidates.
