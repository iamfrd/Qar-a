# Skill Evolution and Capability Benchmarking

Qarğa's self-improvement loop now separates four responsibilities: skill/capability research, approved candidate authoring, independent capability evaluation, and persistent system review. Real Work OS evidence and agent performance trigger research; they do not directly rewrite active skills.

The researcher first inventories existing skills and failed prior attempts, then chooses the smallest intervention. A candidate is benchmarked against the current baseline using disjoint diagnostic, validation, and hidden-holdout cases. Critical-case failure or protected-category regression blocks advancement even when the aggregate score rises. Passing benchmark evidence only advances the change to a minimum three-real-task pilot. Permanent PROVEN promotion remains controlled by policy and owner approval.

Skill scorecards are intended to answer whether a reusable skill materially improves agent quality, safety, regression rate, rework, and cost/time efficiency. Cost optimization must never override correctness or safety.

The design is adapted from EvoSkill's failure-driven proposal, evaluation, feedback-history, frontier, and anti-overfitting ideas, rewritten for Qarğa's coordinator-led Work OS and human-governed evolution architecture. EvoSkill's OpenCode-specific generator and git-branch frontier are intentionally not copied.
